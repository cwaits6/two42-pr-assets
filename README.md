# two42-pr-assets

Screenshots shown in [cwaits6/two42](https://github.com/cwaits6/two42) pull requests, in `pr/<number>/`.

Runs commit straight to `main`. PR links are pinned to a commit, so they keep working after the PR merges. Only seeded test data goes here: everything in this repo is public, and removing a file does not remove it from history.
